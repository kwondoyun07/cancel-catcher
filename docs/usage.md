# 사용법

## 준비

1. 예매 사이트에서 좌석 배치도를 띄워 둡니다.
2. `uv run main.py`로 매크로를 켜고, 매크로 창을 한 번 클릭합니다. 단축키는 매크로 창이 맨 앞에 있을 때만 받습니다.
3. 클릭하지 말고 마우스만 브라우저 위로 옮긴 뒤 키를 눌러 위치를 저장합니다.

| 정할 것 | 방법 |
|---|---|
| 구역 수 | 창의 "구역 수"에 1~10 입력 |
| 구역 위치 | 구역 위에 마우스를 올리고 1~9, 0 (0은 구역 10) |
| 찾을 영역 | C를 누른 뒤 화면에서 드래그. Esc나 오른쪽 클릭은 취소 |
| 찾을 색 | E(마우스 아래 색 저장), 직접 입력, "고르기" 중 하나 |
| 좌석지정 완료 버튼 (선택) | 버튼 위에 마우스를 올리고 F |
| 새로고침 계속 버튼 (선택) | G |
| 지정석 펼치기 버튼 (선택) | H |

칸 색으로 준비 상태를 알 수 있습니다. 노랑은 꼭 정해야 하는 것, 회색은 선택, 초록은 저장된 것입니다.
구역, 찾을 영역, 찾을 색을 모두 정해야 시작할 수 있습니다.

입력칸에서 타자를 치는 동안에는 단축키를 받지 않습니다. Enter를 누르거나 칸 밖을 누르면 적용됩니다.

### 찾을 색 입력

다음 형식을 모두 받습니다.

- `#7C68EE`, `7c68ee`, `#abc`
- `124, 104, 238`, `(124 104 238)`

"고르기"를 누르면 색 선택 창이 뜹니다. 그 안의 "화면 색 선택"으로 사이트의 색을 바로 찍을 수도 있습니다.

## 실행 중

시작을 누르면 다음을 반복합니다.

1. 구역 1부터 차례로 누르고, 누를 때마다 클릭 간격만큼 기다린 뒤 찾을 영역에서 빈자리 색을 찾습니다.
2. 찾으면 그 자리를 누르고, F를 저장했다면 좌석지정 완료까지 누른 뒤 멈춥니다.
3. 20분마다 F5를 누르고, 저장해 둔 새로고침 계속(G)과 지정석 펼치기(H)를 차례로 누릅니다.

I는 어디서나 매크로를 멈춥니다. 매크로가 브라우저를 누르는 동안에는 매크로 창이 뒤로 가기 때문입니다.
실행 중에는 찾을 영역을 다시 그릴 수 없습니다. 정지한 뒤에 그리세요.

## 신호등

| 표시 | 뜻 |
|---|---|
| 노랑 램프 | 대기, 멈춤 |
| 초록 램프 | 찾는 중 |
| 빨강 램프 | 오류. 문구에 이유가 나옵니다 |
| 상자 전체가 초록 | 빈자리를 눌렀음 |

## 알아 둘 점

- 여러 모니터에서 동작합니다. 드래그 화면은 마우스가 있는 모니터에 뜹니다.
- 빈자리는 찾을 영역의 위 줄부터 왼쪽에서 오른쪽 순서로 찾고, 처음 찾은 픽셀을 누릅니다.
- 색은 값이 정확히 같은 픽셀만 찾습니다.
