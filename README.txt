검정구역 취켓팅 매크로
======================

필요 패키지:
    pip install pynput pyautogui PySide6-Essentials

실행:
    python 검정구역_취켓팅_매크로.py

단축키:
    A: 좌석영역 1 저장
    B: 좌석영역 2 저장
    C: 색상 탐색 시작점 저장
    D: 색상 탐색 끝점 저장
    E: 현재 마우스 위치의 RGB 저장
    F: 좌석지정 완료 위치 저장
    G: 새로고침 계속 위치 저장
    H: 지정석 펼치기 위치 저장
    I: 매크로 정지

주의:
    이 프로그램은 화면/마우스 자동화를 사용하므로 실행 전에
    대상 프로그램의 이용약관 및 자동화 정책을 확인하세요.
