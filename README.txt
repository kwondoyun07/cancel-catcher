검정구역 취켓팅 매크로
======================

필요 도구:
    uv (https://docs.astral.sh/uv/)

실행:
    uv run 검정구역_취켓팅_매크로.py
    (처음 실행할 때 필요한 패키지가 자동으로 설치됩니다.)

공통 컴포넌트 미리보기:
    uv run components.py
    (브라우저에 컴포넌트 모음 페이지가 열립니다.)

단축키:
    A~H는 매크로 창이 맨 앞에 있을 때만 동작합니다.
    (창을 한 번 클릭해 두고, 브라우저 위에 마우스만 올린 채 키를 누르세요.)
    I(정지)는 어디서나 동작합니다.

    A: 좌석영역 1 저장
    B: 좌석영역 2 저장
    C: 색상 탐색 영역 그리기 (누른 뒤 화면에서 드래그, Esc로 취소)
    E: 현재 마우스 위치의 RGB 저장
    F: 좌석지정 완료 위치 저장
    G: 새로고침 계속 위치 저장
    H: 지정석 펼치기 위치 저장
    I: 매크로 정지

주의:
    이 프로그램은 화면/마우스 자동화를 사용하므로 실행 전에
    대상 프로그램의 이용약관 및 자동화 정책을 확인하세요.
