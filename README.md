# 검정구역 취켓팅 매크로

예매 사이트 좌석 배치도에서 취소표(빈자리)를 자동으로 잡는 윈도우용 개인 도구입니다.
구역을 차례로 눌러 배치도를 새로 고치고, 지정한 영역에서 빈자리 색을 찾으면 그 자리와 "좌석지정 완료"를 누릅니다.

## 실행

[uv](https://docs.astral.sh/uv/)가 필요합니다.

```powershell
uv run main.py
```

처음 실행할 때 필요한 패키지가 자동으로 설치됩니다.
